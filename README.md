# TheRepeator

An Android application designed for security researchers, BugBounty hunters and developers to perform HTTP inspection, manipulation, and automated testing directly from their mobile devices.

I searched for an app that would do this without rooting the phone and didn't find any so i've used some help to create one that would be useful.

![Logo](app/src/main/res/mipmap-xxhdpi/ic_app_logo.png)

## Key Features

- **Repeater**: Send, modify, and resend HTTP requests.
- **Intruder**: Automate security testing with a payload library. Supports custom markers (`§`) and categorized predefined payloads (HTTP Methods, Headers, etc.).
- **Proxy Browser**: An integrated browser with traffic interception. Intercept, view, and modify requests.
- **Decoder / Encoder**: Chain multiple transforms (Base64, URL, Hex, Gzip, JWT, etc.) to analyze or prepare data.
- **WebSocket Monitor**: Real-time monitoring and sending of WebSocket messages.
- **Requests History**: Log all HTTP traffic with advanced search, filtering (JS, JSON, XML, etc.).
- **Response Viewer**: Deep response analysis.

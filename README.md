# TheRepeator

A mobile app for HTTP inspection, Repeater, Intruder, and Decoder features.

## Features
- **Repeater**: Send and modify HTTP requests with history.
- **Intruder**: Automate attacks with custom payloads.
- **Decoder**: Chained encoding/decoding transforms.
- **WebSocket**: Monitor and send WS messages with auto-reconnect.
- **History**: Full request log with advanced search and filtering.
- **Browser**: Integrated WebView with interception capabilities.
